Bash scriptingReference 01
Quick reference

Run a Bash script

Choose whether to name Bash yourself or let the executable file choose its interpreter.

Two launch forms

# Invoke Bash to read the file
bash report.sh

# Let Linux launch the executable via its shebang
chmod u+x report.sh
./report.sh
  • bash report.sh explicitly selects Bash; no execute bit is required.
  • ./report.sh requires execute permission and uses the first line to select an interpreter.
  • #!/usr/bin/env bash finds Bash through PATH.
  • bash -n report.sh checks syntax without executing the script.
  • Relative file paths are resolved from the process's current working directory.

Primary source: GNU Bash Manual · Shell Scripts.

Common checks

command -v bash
head -n 1 report.sh
ls -l report.sh
