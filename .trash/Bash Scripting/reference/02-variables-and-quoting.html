Values, quoting, and configuration

Keep each value intact as it crosses from a caller's environment into a command.

Assignment and expansion

app_name='billing api'   # no spaces around =
printf '%s\n' "$app_name"
printf '%s\n' "${app_name}_worker"
  • Use the bare name on the left side of an assignment; use $name to expand it.
  • Use ${name} when braces clarify where the name ends.
  • Use "$value" for a command argument that may contain spaces or wildcard characters.
  • Single quotes preserve literal text; double quotes allow variable expansion.

Deployment configuration

app_name=${APP_NAME:?Set APP_NAME}
deploy_env=${DEPLOY_ENV:-staging}
DEPLOY_ENV=test bash report.sh
export DEPLOY_ENV=test
  • ${NAME:-fallback} uses a fallback if unset or empty.
  • ${NAME:?message} stops with an error if unset or empty.
  • NAME=value command sets the environment for one command.
  • export NAME=value makes it available to child processes launched later by that shell.

Primary sources: GNU Bash Manual on Quoting, Parameter Expansion, and Shell Expansions. See also ShellCheck SC2086.
