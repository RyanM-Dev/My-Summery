# Mission: PostgreSQL for Applications and Operations

## Why

Build practical PostgreSQL skill for both application development and database operations: write reliable SQL and schemas for backend services, then diagnose query and concurrency behavior with evidence.

## Success looks like

- Turn backend requirements into SQL queries, data types, constraints, and transactions that preserve business rules.
- Read query plans and use indexes and PostgreSQL statistics to make evidence-based performance changes.
- Explain how concurrent transactions behave and design application handling for conflicts and retryable failures.
- Evaluate PostgreSQL extensions and advanced features against operational and version constraints.

## Constraints

- Self-paced course with one short, focused lesson for each numbered chapter in the 2026 *The Art of PostgreSQL* contents.
- Use practical SQL, concrete scenarios, retrieval practice, and small exercises; keep concepts connected to application and operations work.
- Use PostgreSQL 18 documentation as the current baseline and call out version-dependent behavior.
- The local workspace does not include the book text. Lessons must teach the public chapter topics independently and link to the book and authoritative documentation without implying access to unseen passages.

## Out of scope

- Other database engines.
- Deep platform-specific deployment procedures unless a later lesson or user request needs them.
