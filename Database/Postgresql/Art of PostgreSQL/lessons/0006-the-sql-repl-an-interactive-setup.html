Understand the idea

`psql` is a practical development and operations tool, not just a place to type SQL. Learn its startup configuration, transactions, schema discovery, reporting features, and editor integration. Meta-commands such as `\dt` are interpreted by `psql`; they are not SQL sent to the server. Start with the result the application needs or the rule the database must protect. Choose a PostgreSQL feature that expresses that requirement, then identify evidence that would show it is correct.

Worked example

-- psql meta-commands (run at the psql prompt)
\dt
\d+ public.orders

Use `\dt` to list tables and `\d+` to inspect a relation. These are client commands handled by psql, not SQL statements sent to PostgreSQL.

Practice

Use psql to list tables, inspect one relation, and run a report query. Identify which commands are psql meta-commands.

Do not infer performance from a tiny table or correctness from one happy-path row. Choose evidence that exposes the behavior you are learning.
