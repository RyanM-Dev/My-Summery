Understand the idea

Aggregates reduce rows into groups; grouping sets compute several grouping levels together. CTEs name intermediate relations, recursive CTEs traverse hierarchies, and set operations combine query results. PostgreSQL also offers `DISTINCT ON` for a concise first-row-per-group pattern when ordering is explicit. Start with the result the application needs or the rule the database must protect. Choose a PostgreSQL feature that expresses that requirement, then identify evidence that would show it is correct.

Worked example

WITH monthly AS (
  SELECT date_trunc('month', created_at)::date AS month, sum(total) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT month, revenue FROM monthly WHERE revenue > 0 ORDER BY month;

The CTE names an intermediate relation. Add filters at the appropriate stage: `WHERE` before grouping, `HAVING` after grouping.
