Worked example

INSERT INTO orders (customer_id, total)
VALUES ($1, $2)
RETURNING id, created_at;

`RETURNING` reports the row produced by the write without a second lookup. Parameterize values and use a transaction when multiple changes form one unit.

Practice

Insert a row with RETURNING, update it with a predicate, and delete a disposable row. Verify each affected-row result.

Do not infer performance from a tiny table or correctness from one happy-path row. Choose evidence that exposes the behavior you are learning.
