Data Manipulation and Concurrency

This is the compressed reminder for this course unit. Follow a lesson for the explanation and practice; use the official documentation when you need exact behavior.

Keep these ideas handy

  • Transactions make related writes atomic.
  • Isolation and locks determine concurrent outcomes.
  • Retry transaction failures when PostgreSQL says the outcome is unsafe.
