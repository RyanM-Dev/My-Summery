to give access to jenkins on docker comands we should mount its volume into jenkins container, and also to have previous data we should mount previous docker volume of jenkins to the container so the command is (after stopping old instance):
docker run -p 8080:8080 -p 50000:50000 -d \
-v jenkins_home:/var/jenkins_home \
-v /var/run/docker.sock:/var/run/docker.sock jenkins/jenkins:lts

then we have to install docker inside the jenkins and give permissionto it so it can run docker comands:
curl  https://get.docker.com  >  dockerinstall && chmod 777 dockerinstall && ./dockerinstall

then we have to give permisiion of docker.sock to all group so the Jenkin user can use it too(we have installed docker with root user!)

then we enter the jenkins container as normal user and try docker pull redis to test the access. and if this test pass, from now on docker commands in jenkins can execute
