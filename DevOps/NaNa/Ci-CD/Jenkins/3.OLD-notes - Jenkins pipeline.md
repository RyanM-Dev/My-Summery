1.jenkins pipeline is better than free style because on free style we rely on plugins
2.with pipellines we can execute 2 tasks inparallel
3.with pipeline we can have complex ci/cd where in freestyle we will face different limitations in complex ci/cd
4.with freestyke we need different plugins in multiple jobs that we have to manage them
5.with pipeline + groovi we can have easily programing concepts like conditionals or varaibles and etc


we save jenkins pipeline in 'Jenkinsfile' in the code base.

(ai explain basic groovi for jenkins)
simple pipeline in groovi:
 pipeline{
     agent any
     
     stages{
         stage ("build"){
             steps{
                 echo 'building the application...'
             }
         }
          stage ("test"){
             steps{
                 echo 'testing the application...'
             }
         }
         stage ("deploy"){
             steps{
                 echo 'deploying the application...'
             }
         }
     }
     
 }
