containers were availabe before Docker, but docker is a realy userfreindly container tool

when we install docker, we install docker Engine

docker Engine parts:
	1-Docker server :responsible for pulling images,managing images and containers
	2-Docker API : interacting with Docker Server
	3- CLI : comand line interface: client to execute docker commands
Docker Server parts:
	1- container runtime: responisble for pulling images,managing container lifecycle
	2- Volumes: Persisting data
	3- Network : configuring network for container communication
	4-build own docker images
docker is powerfull because its provide all this functionalities in one application!

there are services that provide some of these functionalities, like containerD that provide container runtime for images even docker images or crio service
or we have services only to build images like buildah
