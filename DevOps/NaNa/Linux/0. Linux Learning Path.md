## 🗺️ How the Topics Build

```mermaid
flowchart LR
    A[Shell tools] --> B[Edit files]
    B --> C[Configure shell environment]
    C --> D[Manage users and groups]
    D --> E[Set ownership and permissions]
    E --> F[Understand networking]
    F --> G[Configure server access]
```

The first topics help you work in a shell. The later topics build toward configuring a server with separate accounts, controlled privileges, and SSH access.
