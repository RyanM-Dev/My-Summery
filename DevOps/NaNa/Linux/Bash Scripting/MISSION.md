# Mission: Bash for Linux and DevOps Work

## Why
Learn Bash to turn routine Linux and DevOps operations into small, repeatable scripts that work predictably on a workstation and in automation such as CI jobs.

## Success looks like
- Create and run a Bash script directly and explain how its interpreter is selected.
- Pass configuration safely, including values containing spaces, and explain what a child process inherits.
- Build small operational helpers for host checks, logs, backups, and deployment workflows.

## Constraints
- Teach from fundamentals toward advanced use, one practical skill at a time.
- Use short interactive lessons, retrieval practice, and useful references.
- Ground Bash material in SDGL, Linux Bible, CompTIA Linux+, and official Bash documentation.

## Out of scope
- No adjacent topics have been ruled out; begin with safe local scripts before system-changing automation.
