Arguments belong to the invocation

Pass inputs to a Bash script

Give a script a release name and an artifact path from the command line, even when either value contains spaces.

Mission: Make small automation reusable across runs without editing the script for every release.

One mental model

Arguments are separate values after the script name

When you invoke a script, values after its filename become positional parameters. Quote a multiword value when you call the script, and quote the parameters when the script uses them.

bash show-inputs.sh 'billing api' 'release bundle.tar.gz'
Script identity$0

The script name or path used to invoke it.

First value$1

The first argument after the script filename.

Argument count$#

How many values the caller supplied.

All values"$@"

Each original argument kept as its own value.

Bash assigns positional parameters from the command's arguments. Its manual distinguishes "$@", which preserves the individual values, from a single joined string. Read: Positional Parameters and Special Parameters.

Four-minute practice

Print each received value

Save this as show-inputs.sh. printf repeats its format for each value supplied by the quoted "$@".

#!/usr/bin/env bash

printf 'Script: %s\n' "$0"
printf 'Argument count: %s\n' "$#"
printf 'First value: <%s>\n' "$1"
printf 'Received value: <%s>\n' "$@"

Run it with two values, both containing spaces:

bash show-inputs.sh 'billing api' 'release bundle.tar.gz'
Script: show-inputs.sh
Argument count: 2
First value: <billing api>
Received value: <billing api>
Received value: <release bundle.tar.gz>

The environment value from Lesson 2 and a command-line argument are different input channels. CI jobs often use both: environment values for configuration, arguments for the particular file or operation being processed.

Interactive alternative: read -r -p 'Environment: ' deploy_env asks a person at a terminal. Use -r so backslashes stay literal. Automation should usually get its inputs from arguments or environment values so it does not wait for someone to answer a prompt.
