One operation, repeated safely

Loop over a batch of files

Count lines in every .log file in a practice folder, without breaking filenames that contain spaces.

Mission: Turn one useful Linux command into a repeatable batch operation.

One mental model

A for loop gives one matching path at a time

The glob *.log expands into matching paths. The loop assigns each result to log_file; quoting that variable keeps a path with spaces together when it reaches wc.

Bash runs the loop body once per word in its expanded list. The Bash manual describes the for, while, and until constructs.

Five-minute practice

Count lines in practice logs

Create two sample logs in a dedicated practice directory. Re-running these commands replaces only these named practice files.

mkdir -p "$HOME/bash-labs/lesson-6"
printf 'WARN starting\nERROR 503\n' > "$HOME/bash-labs/lesson-6/api one.log"
printf 'Started\nReady\nListening\n' > "$HOME/bash-labs/lesson-6/worker.log"

Save this as count-logs.sh:

#!/usr/bin/env bash

log_dir="$HOME/bash-labs/lesson-6"

for log_file in "$log_dir"/*.log; do
    [[ -f "$log_file" ]] || continue
    wc -l -- "$log_file"
done

The directory prefix is quoted, while *.log remains a glob so Bash can expand it. If nothing matches, Bash leaves the pattern unchanged; the file test fails and continue skips it. Run the loop with:

bash count-logs.sh
2 /home/learner/bash-labs/lesson-6/api one.log
3 /home/learner/bash-labs/lesson-6/worker.log

Your home path will differ. Notice that api one.log is handled as one filename.
