Inputs, checks, and exit status

Pass values into a script, check prerequisites, and report whether an operation succeeded.

Read command-line arguments

#!/usr/bin/env bash

printf 'Script: %s\n' "$0"
printf 'Argument count: %s\n' "$#"
printf 'First argument: %s\n' "$1"
printf 'Argument: %s\n' "$@"

config_file=${1:-./release.env}
  • $0 is the invoked script name or path.
  • $1 is the first argument; $# is the number of arguments.
  • Quote "$@" to pass every argument as its own value, including values with spaces.
  • ${NAME:-fallback} uses a fallback when NAME is unset or empty.

Check a prerequisite and return status

if [[ -f "$config_file" && -r "$config_file" ]]; then
    printf 'Config is ready: %s\n' "$config_file"
else
    printf 'Config is missing or unreadable: %s\n' "$config_file" >&2
    exit 1
fi
  • Status 0 means success; a non-zero status signals failure.
  • [[ -f path ]] checks for a regular file; [[ -r path ]] checks readability.
  • Use command && next_command when the next command should run only after success.
  • Read $? immediately; a later command replaces the last status.
  • Send an error message to standard error with >&2.

Primary sources: GNU Bash Manual on Positional Parameters, Special Parameters, Exit Status, and Conditional Expressions.
