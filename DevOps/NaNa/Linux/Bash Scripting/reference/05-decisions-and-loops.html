Decisions and file batches

Validate an input, choose one known action, and safely repeat a command across matching files.

Branch on status or a known value

if [[ -f "$manifest" && -r "$manifest" ]]; then
    printf 'Ready\n'
else
    printf 'Cannot read manifest\n' >&2
    exit 1
fi

case "$environment" in
    dev|test) printf 'Run checks\n' ;;
    staging)  printf 'Prepare staging\n' ;;
    production) printf 'Require approval\n' ;;
    *) printf 'Unknown environment\n' >&2; exit 2 ;;
esac
  • Use if to branch on a command or test's exit status.
  • Use case to match a value against known patterns.
  • dev|test matches either value; *) is the fallback.
  • End each case branch with ;;.

Loop over matching files

for log_file in "$log_dir"/*.log; do
    [[ -f "$log_file" ]] || continue
    wc -l -- "$log_file"
done
  • Leave *.log unquoted so Bash expands it to matching paths.
  • Quote "$log_file" so spaces remain part of one filename.
  • If no files match, the literal pattern can remain; the -f guard skips it.
  • continue skips to the next loop item; done closes the loop.

Primary sources: GNU Bash Manual on Conditional Constructs, Conditional Expressions, and Looping Constructs.
